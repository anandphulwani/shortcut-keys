ShortcutKeys browser access

This grants broad page access, but credentials are released only when an enabled rule matches the selected tab's exact origin and the desktop app is unlocked. HTTP login pages are not encrypted in transit. Use HTTPS whenever possible.

For Edge InPrivate windows, open edge://extensions, select ShortcutKeys Browser Bridge → Details, and turn on Allow in InPrivate. The extension cannot change this browser-controlled setting.

Authorize only specific sites instead

Add an exact site origin, including its port. Cross-origin login iframes need both origins approved.
